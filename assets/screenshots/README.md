# Screenshots 截图目录

请在此处添加项目工作台的实际截图，以使 README 更加图文并茂。

## 建议截图列表

| 文件名                  | 说明                     | 如何获取          |
|---------------------------|------------------------------|---------------------------|
| `dashboard.png`           | 概览页面               | 首页默认视图     |
| `scholars.png`            | 学者名录列表           | Scholars 标签页        |
| `scholars-detail.png`     | 学者详情弹窗           | 点击任一学者卡片 |
| `timeline.png`            | 时间轴                    | Timeline 标签页       |
| `graph.png`               | 知识图谱                 | Graph 标签页          |
| `influence.png`           | 影响网络                 | Influence 标签页      |
| `books.png`               | 经典著作列表             | Books 标签页          |
| `browse.png`              | 证据库                     | Browse 标签页         |

## 操作步骤

1. 在本地运行：
   ```bash
   python workbench/server.py
   ```
2. 打开 http://127.0.0.1:8125
3. 切换到对应标签页
4. 使用浏览器内置截图工具或扩展程序截图
5. 上传到此目录，命名建议如上表

提交后，在主 README.md 中添加对应图片引用即可。
